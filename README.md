# Smart Buy PK

A static, responsive shopping research helper for Pakistani shoppers.

## Files
- `index.html` — complete website (HTML, CSS, and JavaScript are included in this single file).

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `Smart-buy-pk`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.

## Important note
This saved version is a static front-end website. It does not include a backend, database, user accounts, or automatic live price collection. Product research links open external search pages, and the price comparison tool compares prices entered by the visitor.
